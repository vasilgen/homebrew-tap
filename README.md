# vasilgen/homebrew-tap

Homebrew casks by [vasilgen](https://github.com/vasilgen).

```sh
brew install --cask vasilgen/tap/instantfocus
```

| Cask | What |
| --- | --- |
| `instantfocus` | [InstantFocus](https://github.com/vasilgen/instant-focus): jump to any app with one shortcut, on any Space, without the animation |

If Homebrew says the tap is not trusted: `brew trust --cask vasilgen/tap/instantfocus`.
